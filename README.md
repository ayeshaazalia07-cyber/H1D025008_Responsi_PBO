## Petunjuk Compile dan njalanin program di terminal

Pastiin udah nge instal **Java Development Kit (JDK)**. Terus Buka (CMD), buka folder penyimpanan file-file .java

1. **Compile seluruh file Java:**
   javac BisaKlakson.java BisaTurbo.java MobilF1.java Mercedes.java Ferrari.java MainF1.java

2. **Jalankan program utama (MainF1):**
   java MainF1
